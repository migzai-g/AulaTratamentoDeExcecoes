# Atividade Acadêmica sobre Tratamento de Exceções em Java.

## Sobre

Programa em Java que realiza operações matemáticas usando **classe abstrata**,
**herança** e **exceção personalizada**.

## Conceitos aplicados

- Classe abstrata com método abstrato
- Herança e sobrescrita de método (@Override)
- Exceção personalizada estendendo Exception
- Bloco try-catch para tratamento de erros em tempo de execução
